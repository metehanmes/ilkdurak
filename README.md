# İlk Durak

Sevdiğin kişiyi ortak anılarınızın geçtiği yerlere götüren, her durakta bir anının açıldığı kişisel sürpriz yolculuk.

- `web/` — site (çerçevesiz, düz HTML/CSS/JS). Ayarlar: `web/assets/js/config.js`
- `supabase/migrations/` — veritabanı (Supabase SQL editöründe çalıştırılır, tekrar çalıştırılabilir)
- `test/` — yerel test ortamı, veritabanı kural testleri ve uçtan uca telefon testleri
- `tools/build.sh <adres>` — yayın kopyasını `dist/` içine hazırlar
